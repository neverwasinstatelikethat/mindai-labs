# Снимки экрана — `screenshots/`

## Как снимки соотносятся с функциональностью

### Пользовательский сценарий (демо для жюри)

1. **`01_homepage`** — Пользователь открывает главную страницу, видит описание платформы и пример ответа
2. **`02_chat_empty`** — Переходит в рабочее пространство, видит пустой чат
3. **`03_chat_response`** — Задаёт вопрос, получает структурированный ответ с доказательствами
4. **`04_graph`** → **`05_graph_expanded`** → **`06_graph_search`** — Открывает граф знаний, расширяет узлы, ищет связи
5. **`07_feedback`** — Как эксперт, оставляет обратную связь по утверждениям
6. **`08_findings`** — Просматривает все утверждения базы с доказательствами
7. **`09_dashboard`** — Администратор проверяет состояние системы
8. **`10_graph_map`** — Демонстрация масштабируемости визуализации

### Покрытие возможностей

| Возможность | Снимки |
|---|---|
| Проверяемые ответы с доказательствами | `03_chat_response`, `08_findings` |
| Числовые данные с единицами измерения | `03_chat_response`, `08_findings` |
| Обнаружение противоречий | `03_chat_response` |
| Выявление пробелов | `03_chat_response` |
| Визуализация графа знаний | `04_graph`, `05_graph_expanded`, `06_graph_search`, `10_graph_map` |
| Экспертная обратная связь | `07_feedback` |
| Панель управления | `09_dashboard` |
| Ролевая модель | Переключатель ролей виден в шапке на всех снимках рабочих экранов |
