# Frontend

Пользовательский интерфейс «Научного Клубка»: SvelteKit 2, Svelte 5 и TypeScript. Интерфейс на русском, данные и доступ приходят из backend через `src/lib/api.ts`.

## Маршруты

- `/` — коротко объясняет продукт и ведёт к вопросу или входу.
- `/research` — чат: вопрос, ответ, источники и поле для следующего сообщения.
- `/findings` — поиск утверждений и просмотр доказательств.
- `/numbers` — сравнение чисел, расхождения и пробелы.
- `/graph` — карта связей между утверждениями и сущностями.
- `/account` — профиль, доступные действия и история собственной работы.

## Разработка

Из `frontend/`:

```bash
npm install
npm run dev
```

Перед отправкой изменений:

```bash
npm run check
npm run build
```

Для изменений числовой логики доступна `npm run check:numbers`. Проверки, которым нужен backend, запускай только при поднятом локальном контуре.

## Структура

- `src/routes/` — страницы и серверные проверки маршрутов.
- `src/lib/` — API-клиент, типы, форматирование и повторно используемые компоненты.
- `src/lib/terms/` — словари пользовательских подписей.
- `src/app.css`, `src/tokens.css` — общие стили и дизайн-токены.
