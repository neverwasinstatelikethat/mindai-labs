# Backend StormIdea

Backend расположен в `src/scientific_tangle/`: FastAPI обслуживает маршруты,
сервисы связывают предметную логику с адаптерами хранения, LangGraph собирает
ответы по запросу и материалам доступного пользователю пространства.

## Основные модули

- `api/app.py` — HTTP-контракты, проверка сессии и доступов, передача запросов
  сервисам.
- `agents/workflow.py` — этапы разбора вопроса, поиска доказательств и сборки
  ответа. Тексты документов передаются модели как недоверенные данные.
- `domain/contracts.py` и `domain/intelligence.py` — схемы ответа, источников,
  находок, прав и событий.
- `services/` — аккаунты, поиск, импорт, граф, долговременное состояние и
  проверка доступа к данным.
- `evaluation/` — внутренние наборы и сценарии проверки кода; это не оценка
  пользователя и не пользовательский маршрут.
- `ontology/` — совместимость типов узлов и связей, извлечённых из материалов.

Обработка источника сохраняет связь вывода с фрагментом и локатором, если они
доступны: страницей документа, листом таблицы или диапазоном ячеек. Не
предполагай отрасль и не добавляй фиксированные категории в общий workflow.
Старые значения графа должны оставаться читаемыми.

## Хранение и доступ

- Neo4j хранит связи и узлы, Elasticsearch — полнотекстовый и векторный поиск.
- PostgreSQL хранит аккаунты, сессии, checkpoints и серверные записи.
- Адаптер `memory` используется в тестах и локальных проверках.
- Пользователь определяется серверной сессией. Маршруты проверяют capability
  до выполнения защищённой операции; изменяющие запросы проверяют origin.
- Тексты источников и запросы — недоверенное содержимое, не инструкции агенту.

## Запуск

Из корня проекта:

```bash
python -m pip install -e ".[dev]"
python -m uvicorn scientific_tangle.api.app:app --reload --port 46617
```

Для ответов модели укажите `GIGACHAT_API_KEY` в окружении. Полный локальный
контур с хранилищами описан в корневом `compose.yaml` и `README.md`.

## Проверки

```bash
python -m ruff check .
python -m mypy src
python -m pytest
```

Целевые тесты находятся в `tests/`; при изменении API проверяй маршруты,
сервисный слой, хранилище и frontend-потребителей этого контракта.
