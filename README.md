# Научный Клубок

Agentic GraphRAG-платформа, которая превращает разрозненные R&D-документы горно-металлургической отрасли в проверяемую карту знаний: сущности, числовые условия, эксперименты, противоречия, экспертиза и точные ссылки на первоисточники.

## Почему не обычный RAG

Обычный vector RAG хорошо находит похожие фрагменты, но слабо отвечает на вопросы с несколькими ограничениями, сравнивает несовместимые эксперименты и теряет provenance чисел. «Научный Клубок» строит evidence graph и выполняет hybrid retrieval: Elasticsearch + embeddings + ограниченный обход Neo4j + GraphRAG community summaries.

## Конкурсный сценарий

1. Импорт RU/EN документов и экспериментальных таблиц.
2. Наблюдаемый pipeline извлекает сущности, связи, числа, условия и источники.
3. Исследователь задаёт multi-hop вопрос с диапазоном, географией и периодом.
4. Система выдаёт сравнение, consensus, disagreements, gaps и экспертов.
5. Любой тезис раскрывается до страницы/ячейки источника и пути в графе.
6. Эксперт исправляет Claim; feedback сразу влияет на доверенный слой и попадает в evaluation dataset.
